# Product photos

The site looks for one photo per product here: `images/<product-id>.jpg`.
If a file is missing, the card shows a neutral icon tile instead, so nothing breaks.

Use photos you are allowed to use (your own, or free-licence sources such as Unsplash or Pexels; check each licence).
Use roughly square photos, about 600x600 px.

File names expected:
mug, bottle, pan, spice, mouse, keyboard, speaker, earbuds, bank, cable, tee, jacket, shoes, cap,
wallet, watch, shades, bag, lamp, clock, notes, yoga, dumbbell, skip  (all `.jpg`)

Example: `images/mug.jpg`, `images/mouse.jpg`
